
#  أداة بسيطة وفعالة بلغة Python لدمج ملفات المعاجم والقواميس (ألماني - عربي) المقسمة إلى عدة أجزاء CSV، وتحويلها إلى صيغ مدمجة وجاهزة للاستخدام في برامج المعاجم مثل **PyGlossary** و **Anki**.


---

## المميزات الرئيسية

* **الدمج التلقائي:** يجمع ملفات الأجزاء (`vol1.csv` إلى `vol6.csv`) في ملف واحد شامل تلقائياً.
* **دعم الاتجاه من اليمين لليسار (RTL):** توليد كود HTML تلقائياً لتنسيق الترجمة العربية وعرضها بالشكل الصحيح داخل القواميس والتطبيقات.
* **إخراج مزدوج:**
  1. **ملف خام (Master RAW):** يعطي البيانات مقسمة (`Word`, `Type`, `Meaning`) للتعديلات المستقبلية.
  2. **ملف جاهز (PyGlossary Ready):** يحتوي على الكلمة والتنسيق البرمجي المباشر للتحويل إلى صيغ Stardict أو MDict أو Anki.
* **المرونة في عناوين الأعمدة:** يتعرف السكريبت تلقائياً على حقل المعنى سواء كان باسم `Meaning` أو `Definition`.

---

## كيفية التخصيص والتعديل

تستطيع تعديل السكريبت بسهولة ليتناسب مع مجلداتك وأسماء ملفاتك:

### 1. تغيير مسار المجلد (Folder Path)
بشكل افتراضي، يقرأ السكريبت من مسار محدد في نظام Windows. لجعله يعمل على أي جهاز (مسار نسبي):
```python
# المسار الحالي:
input_folder = r"D:\de ar csv"

# للتعديل وجعله يقرأ من نفس مجلد السكريبت (أفضل لـ GitHub):
input_folder = "."

```

### 2. تعديل عدد الأجزاء (Volumes)

إذا كان لديك عدد أجزاء مختلف عن 6 ملفات، عدّل نطاق الحلقة `range`:

```python
# لدمج من vol1 إلى vol10 مثلاً:
for i in range(1, 11):

```

### 3. تخصيص تنسيق الـ HTML للتعريف

يمكنك تغيير طريقة ظهور الكلمة ونوعها (اسم، فعل، إلخ) داخل القاموس:

```python
# التنسيق الحالي (RTL + نص عريض للمعنى + نوع الكلمة بين قوسين):
html_def = f'<div dir="rtl" align="right"><b>{meaning}</b> ({word_type})</div>' if word_type else f'<div dir="rtl" align="right"><b>{meaning}</b></div>'

# مثال لتغيير اللون أو حجم الخط:
# html_def = f'<div dir="rtl" style="font-size:16px;"><b>{meaning}</b> <span style="color:gray;">({word_type})</span></div>'

```

## طريقة التشغيل

### المتطلبات

السكريبت يعمل باستخدام مكتبات Python القياسية (`csv`, `os`) ولا يحتاج لتثبيت أي حزم خارجية.

### الخطوات

1. قم بتثبيت أو تحميل الملفات:
```bash
git clone https://github.com/Mohamed-bouri/csvagent.git
cd csvagent

```


2. ضع ملفات הـ CSV الخاصة بك باسم (`vol1.csv` إلى `vol6.csv`) داخل المجلد المحدد.
3. قم بتشغيل السكريبت:
```bash
python csvagent.py

```

##  شكل ملفات الإدخال المتوقع (Input Format)

يجب أن تحتوي ملفات الـ CSV الإدخالية على ترويسة (Header) تشمل الحقول التالية:
`Word`, `Type`, `Meaning` (أو `Definition`).

```هذا مثال على التنسيق
Word,Type,Meaning
Haus,Noun,بيت / منزل
laufen,Verb,يركض / يمشي

```
